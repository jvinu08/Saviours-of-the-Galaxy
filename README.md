# Saviours of the Galaxy

A multiplayer space shooter game inspired by the classic arcade game Galaga, built in Python as my Grade 10 Computer Science project.

## About the Game
Team up with a friend and defend the galaxy from waves of alien enemies. Two players, one mission — survive.

## Features
- 2 player local multiplayer
- Waves of enemies inspired by Galaga
- Space shooter gameplay
- Built entirely in Python

## Built With
- Python
- Pygame Zero (pgzrun)

## How to Run
1. Make sure Python is installed on your computer
2. Install Pygame Zero by running this in your terminal:
```
pip install pgzero
```
3. Run the game:
```
pgzrun saviours_of_the_galaxy.py
```
